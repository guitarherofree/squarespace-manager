# Changelog

To publish a release, add a `## x.y.z` section at the top with notes and push to main.

## 0.2.0
- The app is now called **Website**, with a new icon.
- Updates come straight from GitHub releases. Website checks shortly after it opens and then daily, downloads new versions in the background, and installs them when you quit or click **Restart Now**. Check any time with **Website › Check for Updates…**.
- Your sites and snapshots move over from Squarespace Manager automatically.
- Install this version by hand once, because 0.1.0 can't update itself to it. You can then delete the old Squarespace Manager app.

## 0.1.0
- First build: connect a site and detect its Squarespace version and template, live preview at desktop, tablet and mobile widths, snapshots with change lists, and a plan setting.
